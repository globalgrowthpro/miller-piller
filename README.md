Essential Requirements

Fully responsive desktop, tablet and mobile layouts.

Arabic RTL and English LTR support.

Use the original supplied logo without changing any text or graphical elements.

Search and filtering for equipment.

Equipment image galleries and specifications.

Quote request forms with server-side validation.

Admin-controlled equipment and website content.

Quote status tracking and notifications.

SEO-friendly URLs and metadata.

Secure authentication, permissions and file uploads.

Reusable components and maintainable Laravel architecture.

Implementation order: Design System → Public Pages → Equipment Catalog → Quote Workflow → Admin Panel → Testing and Deployment.

Important: All sample equipment specifications, contact numbers, availability indicators and dashboard figures displayed in UI mockups are placeholders. Replace them with verified company information.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
